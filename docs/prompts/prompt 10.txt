A Search Landscape Analysis Engine (SLAE) é uma técnica usada em solvers de pesquisa avançados de timetabling e combinatorial optimization para analisar a topologia do espaço de soluções durante a execução.

Ela detecta fenômenos como:

local minima
plateaus
valleys
deceptive landscapes
basins of attraction

Quando o solver percebe que está preso em um vale profundo do landscape, ele muda radicalmente a estratégia de busca.

Essa técnica aparece em pesquisas relacionadas a:

Metaheuristic landscape analysis

Reactive search optimization

Adaptive hyper-heuristics

Automated algorithm configuration

1. Intuição do Landscape

Considere o espaço de soluções como um terreno 3D:

fitness
   ↑
   │        /\        ← ótimo global
   │       /  \
   │   /\_/    \_
   │__/          \____
   └────────────────────→ espaço de soluções

Problemas típicos:

plateau        → região plana
valley         → vale profundo
local optimum  → ótimo local
deception      → caminho errado

Um solver tradicional não sabe em qual região está.

A SLAE tenta inferir a topologia local do landscape.

3. Métricas usadas para analisar o landscape

Solvers avançados usam várias métricas.

1️⃣ Stagnation

Número de iterações sem melhoria.

stagnation = iterations_without_improvement
2️⃣ Fitness slope

Inclinação da curva de fitness.

slope = d(fitness) / d(iterations)

Se:

slope ≈ 0

então estamos em um plateau.

3️⃣ Move success rate

Taxa de movimentos que melhoram a solução.

success_rate = improving_moves / total_moves

Valores típicos:

> 0.3 → região explorável
0.05-0.3 → intensificação
< 0.05 → vale profundo
4️⃣ Diversity collapse

Se diversidade cai muito:

population_entropy ↓

indica:

convergência prematura
5️⃣ Autocorrelation do fitness

Solvers avançados usam:

fitness autocorrelation

Equação:

ρ(k) = corr(f(x), f(x+k))

Alta autocorrelação → landscape suave.

Baixa autocorrelação → landscape caótico.

5. Fitness trajectory tracker

Guarda histórico de fitness.

class FitnessTrajectoryTracker
{
    private array $history = [];

    public function record(float $fitness): void
    {
        $this->history[] = $fitness;

        if (count($this->history) > 200)
        {
            array_shift($this->history);
        }
    }

    public function slope(): float
    {
        $n = count($this->history);

        if ($n < 5) return 0;

        $first = $this->history[0];
        $last  = $this->history[$n-1];

        return ($last - $first) / $n;
    }
}
6. Move success analyzer
class MoveSuccessAnalyzer
{
    private int $success = 0;
    private int $total = 0;

    public function record(bool $improved): void
    {
        $this->total++;

        if ($improved)
        {
            $this->success++;
        }
    }

    public function successRate(): float
    {
        if ($this->total == 0)
            return 0;

        return $this->success / $this->total;
    }
}
7. Plateau detector

Detecta regiões planas.

class PlateauDetector
{
    public function isPlateau(LandscapeFeatures $f): bool
    {
        return
            abs($f->fitnessSlope) < 0.0001
            && $f->successRate < 0.1
            && $f->stagnation > 50;
    }
}
8. Basin detector

Detecta vales profundos.

class BasinDetector
{
    public function isDeepValley(LandscapeFeatures $f): bool
    {
        return
            $f->successRate < 0.02
            && $f->stagnation > 100
            && $f->diversity < 0.2;
    }
}
9. Strategy Switcher

Dependendo do landscape, mudamos heurísticas.

class StrategySwitcher
{
    public function chooseStrategy(LandscapeFeatures $f): string
    {
        if ($f->stagnation > 200)
        {
            return "VLNS";
        }

        if ($f->successRate < 0.05)
        {
            return "EJECTION_CHAINS";
        }

        if ($f->diversity < 0.2)
        {
            return "DIVERSIFICATION";
        }

        return "LOCAL_SEARCH";
    }
}
10. Search Landscape Analyzer

Motor central.

class SearchLandscapeAnalyzer
{
    public function analyze(
        LandscapeFeatures $features
    ): string {

        if ($features->stagnation > 200)
            return "escape_valley";

        if ($features->successRate < 0.05)
            return "deep_valley";

        if ($features->fitnessSlope < 0.0001)
            return "plateau";

        return "normal";
    }
}
11. Integração no solver

Loop principal:

current_solution
      ↓
move
      ↓
evaluate
      ↓
update landscape metrics
      ↓
landscape analysis
      ↓
switch search strategy
Código
$features = $landscape->collectFeatures();

$state = $analyzer->analyze($features);

switch($state)
{
    case "plateau":
        $solver->activateKempeChains();
        break;

    case "deep_valley":
        $solver->activateLNS();
        break;

    case "escape_valley":
        $solver->activateVLNS();
        break;
}
